📜 Formulario Teórico de Diseño Hidráulico
1. Distancia Tridimensional (3D): L = √[ (ΔX)² + (ΔY)² + (ΔZ)² ]
2. Pendiente Lineal (m): m = ( ΔZ / d_horizontal ) × 100%
3. Área Transversal y Caudal (Q): A = ( π · D² ) / 4 | Q = A · v
4. Balance de Presión y Pérdidas: P_final = P_inicial + ΔP_elevación - h_fricción - h_accesorio
